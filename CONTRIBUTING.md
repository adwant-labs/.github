# Contributing to Adwant Labs

Thank you for helping improve Adwant Labs projects.

## Before you begin

1. Read the target repository's README and local contributing instructions.
2. Search existing issues and pull requests to avoid duplicate work.
3. For substantial changes, open an issue first so the approach can be discussed.
4. Never include credentials, private data, or proprietary material in an issue, commit, or example.

## Making a contribution

1. Fork the repository and create a focused branch.
2. Keep the change small and limited to one concern.
3. Add or update tests for behavior changes.
4. Update documentation when public behavior or configuration changes.
5. Run the repository's documented checks locally.
6. Open a pull request with a clear problem statement, solution summary, and verification notes.

## Pull-request expectations

- Explain why the change is needed, not only what changed.
- Link related issues when applicable.
- Preserve backward compatibility unless a breaking change has been discussed.
- Respond constructively to review feedback.
- Ensure commits are your own work or are used under a compatible license.

Maintainers may close incomplete, unsafe, off-topic, or inactive contributions. All participants must follow the [Code of Conduct](CODE_OF_CONDUCT.md).
