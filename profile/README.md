# Adwant Labs

Open-source tools for reliable AI systems, secure agent infrastructure, and developer productivity.

We build practical, testable software for engineers working with AI agents, language-model infrastructure, distributed systems, and modern developer platforms.

## Focus areas

- **Agent reliability and MCP security** — testing, privacy, policy enforcement, and safe tool use.
- **LLM infrastructure** — routing, retrieval, vector systems, and production operations.
- **Developer and data tools** — contracts, static analysis, performance, and schema evolution.
- **Applied research** — reproducible implementations and evaluations for real engineering workflows.

## Projects

Our open-source libraries are being organized here. Featured projects and documentation will be added as they move into the organization.

## Contributing

Contributions, bug reports, and thoughtful technical discussions are welcome. Please read our [contribution guidelines](https://github.com/adwant-labs/.github/blob/main/CONTRIBUTING.md) and the contributing guide in the relevant repository before opening a pull request.

## Security

Please do not disclose vulnerabilities in public issues. Follow our [security policy](https://github.com/adwant-labs/.github/security/policy) and use a repository's private vulnerability-reporting option when available.

## Community

Participation in Adwant Labs projects is governed by our [Code of Conduct](https://github.com/adwant-labs/.github/blob/main/CODE_OF_CONDUCT.md).
